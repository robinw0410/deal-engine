# deal-engine 0.2.1

A small release on top of 0.2.0: the deal list page is localized (`en`/`de`), the "copy as
prompt" button of the search pages is now a switch and **off by default**, and every LLM call
explicitly disallows Bash, WebFetch and WebSearch.

## Upgrade notes

- **Breaking:** the "copy as prompt" button (and its hidden prompt text) is off by default. To get
  it back, set it globally or per search:

  ```yaml
  web:
    copy_prompt: true          # all searches

  searches:
    electronics:
      web:
        copy_prompt: true      # one search (a search's own value wins)
  ```

- `llm.extra_args` that allow Bash, WebFetch or WebSearch via `--tools`/`--allowedTools` are now a
  configuration error.

## Security

- Every LLM call now gets `--disallowedTools Bash WebFetch WebSearch` in addition to the explicit
  `--tools` list (Read/Write for evaluation and prefilter, none for classification), also when
  `llm.extra_args` are set.
- Your own Claude Code settings and hooks still apply to these runs. As a second line of defence,
  deny these tools in the Claude Code settings of the user that runs deal-engine (e.g. a service
  user), `~/.claude/settings.json`:

  ```json
  {"permissions": {"deny": ["Bash", "WebFetch", "WebSearch"]}}
  ```

## Added

- **Deal list localized:** the deal list page (`deal_engine/deals/deals.html`) follows the config
  `locale` (`en`/`de`): all headings, buttons, labels, placeholders, confirmations, empty states,
  status names and number/currency formatting (de: `1.234 €`). Texts live in
  `deal_engine/deals/texts.py`. Statuses are still stored as machine values (`bought`,
  `in progress`, `listed`, `sold`, `scrapped`). This fixes the "Not localized" note of 0.2.0.
- **`web.copy_prompt`** (global, overridable per search with `searches.<name>.web.copy_prompt`)
  switches the "copy as prompt" button of the search pages.
- `--locale` option of the deal server (overrides the config locale); `make serve-demo-de` uses it,
  so the German demo shows the German deal list and price hints.

## Installation

```sh
pip install "deal-engine @ git+https://github.com/robinw0410/deal-engine@v0.2.1"
```

or clone the repository and run `pip install -r requirements.txt` and `make demo`. See the
README for details and the [CHANGELOG](https://github.com/robinw0410/deal-engine/blob/v0.2.1/CHANGELOG.md) for the full history.
